# page-analyser

This project is used to analyse pages use of words, text and other material to find bad practices. This will be using models and my knowledge from media psychology to find persuasive text.

## Setup

Make sure to install dependencies:

```bash
# bun
bun install
bun run build
bun run preview
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# bun
bun run dev
```
